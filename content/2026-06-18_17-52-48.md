## 背景

従来は[PATを用いた認証](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#get-a-personal-access-token)でVSCode拡張を公開していたが
2026年12月1日に[廃止](https://devblogs.microsoft.com/devops/retirement-of-global-personal-access-tokens-in-azure-devops/)されるとのこと
これからは、EntraID認証を用いる必要がある

## VSCode拡張の公開までやってみる

[公式ドキュメント](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#secure-automated-publishing-to-visual-studio-marketplace)があるものの
なかなか手順通りにうまくできず、時間がかかってしまった

### 1. Azure DevOps 連携 (marketplace control)

https://aex.dev.azure.com/
New project => Create
Project Settings => Service Connections => New service connection => Azure Resource Manager =>
Grant access permission to all pipelinesにチェック => Save

### 2. Azure連携 (EntraID認証設定)

https://portal.azure.com/#create/Microsoft.ManagedIdentity => Create
設定 => フェデレーション資格情報 => 資格情報の追加 => GithubActionシナリオ => Craete

### 3. VS Marketplace 連携

Resrouce ID を取得する

```sh
# How to install the Azure CLI: https://learn.microsoft.com/cli/azure/install-azure-cli?view=azure-cli-latest
winget install --exact --id Microsoft.AzureCLI

az login --use-device-code
az rest -u https://app.vssps.visualstudio.com/_apis/profile/profiles/me --resource 499b84ac-1321-427f-aa17-267ca6975798
# copy "id" field from outputted json
```

https://marketplace.visualstudio.com/manage => membersタブ => 追加
先ほどコピーしたIDをUser Nameにして、RoleはContributorを設定

```sh
vsce verify-pat [publisher] --azure-credential
# output: The Personal Access Token verification succeeded for the publisher [publisher].
```

で疎通確認を行う

### 4. publish

ローカルでやるなら

```sh
az login --use-device-code
vsce publish --azure-credential
```

github actionsでやるならログイン不要でそのままpublishできる(EntraID認証の恩恵)

```sh
vsce publish --azure-credential
```
